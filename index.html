Design system, v0.1

One interface for people and agents that act.

Tessera is a design system for products where AI does real work: reading, deciding and changing things on a person's behalf. It defines tokens, components and rules for showing what an agent is doing, asking before it acts, and leaving a trail anyone can audit.

The problem

Agents act without clicks. Can you tell what they did?

AI agents now change settings, edit records and send messages on a person's behalf. Most interfaces give no consistent way to see what happened, approve it, or undo it. Run the same task in both interfaces. The task: an agent fixes a color that fails contrast.

Principles

AI is a first-class user of the system

Most systems add an "AI feature" at the end. Tessera starts from the opposite assumption: every component must work when an agent is the one acting, and every agent action must be readable by a person.

Agents propose, people decide

Anything with side effects passes through an approval gate until the person raises the agent's autonomy.

component: Approval gate

Show the work

Each result carries its steps, inputs and checks. A confident answer without a trace is treated as unfinished.

component: Run trace

Mark what the machine made

Cobalt means an AI wrote it, is running it, or changed it. It is never used on human-authored content.

token: --agent, AI badge

Autonomy is a setting, not a surprise

Three levels: suggest, ask first, act then report. The current level is always visible and one click to change.

control: Autonomy selector

Action contract

What every agent action declares

Components render from a small, shared description of an action. That is what lets the approval gate, the trace and the audit trail look the same in every product.

{
  "intent": "Change --agent-soft-text",
  "scope": { "files": 1, "tokens": 1 },
  "reversible": true,
  "checks": [
    { "name": "contrast >= 4.5", "result": "pass" }
  ],
  "sources": ["tokens.json", "WCAG 2.2 1.4.3"],
  "requires_approval": "autonomy != act",
  "actor": "agent:token-audit"
}

Rules the gate enforces

Irreversible actions always require approval, whatever the autonomy level.

An action with no sources or no checks cannot be applied automatically.

The audit trail records who approved: a person, or a named policy.

Undo is available for the last action until the next one starts.
